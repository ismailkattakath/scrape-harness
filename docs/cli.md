# `examplesite` command reference

GENERATED by `examplesite cli spec --format md` from the argparse tree and pipeline.toml.
Do not edit. `examplesite cli spec --format md --check <this file>` fails on drift.

Handled before parsing, so not in the tables: `examplesite plan <command> ...` (the same as `<command> ... --plan`); `examplesite statusline` (Claude Code's status line: one fast line, never a failure).

## Commands

| Command | Declared | Network | Does |
|---|---|---|---|
| `ab` | utility | site | same N list pages in every page variant -> derived/ab-*.json (no ad pages) |
| `approvals` |  |  | audit the approval ledger: hash chain + signatures (read-only) |
| `approve` | utility | none | approve one exact run plan, once: the operator's Touch ID signs it (Secretive) |
| `breaker` |  |  | the gone-storm breaker's site latch: status, or an audited operator clear (appends) |
| `browser` |  |  | the dedicated browser profile |
| `browser open` | utility | site | open the dedicated profile HEADED to clear a challenge or gate once |
| `claude-settings` |  |  | render/check .claude/settings.json from pipeline.toml |
| `cli` |  |  | this CLI described: the command and flag tree (offline) |
| `cli spec` |  |  | every command, positional and option (consumer plug-ins included) as cli.v1 JSONL, sorted, with its pipeline.toml declaration (stage/utility, network class, inputs, outputs) |
| `cooldown` | utility | none | site cooldowns: status, or an audited operator clear (appends, never deletes) |
| `crawl` |  |  | crawl run control |
| `crawl correct` |  |  | record a run's real END (append-only run_correction; the run record is not rewritten) |
| `crawl resume` | utility | site | continue a stopped run from its persisted queue (no duplicate GETs) |
| `crawl-lists` | stage 1 | site | read list pages -> observations.jsonl (depth-stratified) |
| `fetch-ads` | stage 2 | site | GET ad pages the refetch rule selects -> listings.jsonl |
| `findings` |  |  | the findings register (finding.v1) |
| `incidents` |  |  | run stops and refusals (STATE/ops/incidents.jsonl): list, ack |
| `migrate` | utility | none | COPY an old single root into DATA (synced) and STATE (local); never moves |
| `plugins` |  |  | list registered sources, drivers, variants |
| `probe` |  |  | one-request checks of the site |
| `probe robots` | utility | site | ONE robots.txt GET (no retry) after the egress preflight: clean or not |
| `refresh` |  |  | the ONE on-demand chain ([crawl.refresh] steps, by doit) under ONE bounded Touch ID approval |
| `reparse` | stage 3 | none | re-extract listings from saved ad snapshots, OFFLINE (no new views) |
| `run` |  |  | the declared stages as doit tasks: `run [doit args] [-- args for networked stages]` |
| `validate` |  |  | validate JSON/JSONL against a named contract |
